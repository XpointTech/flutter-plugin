# Xpoint SDK Flutter Plugin

Flutter plugin (pub package `xpoint_sdk`) for Xpoint's geolocation compliance checking.
Supports Android, iOS, macOS and Windows.

The documentation is published on the Xpoint portal:
- Integration guide: https://docs.xpoint.tech/integration/flutter
- Release notes: https://docs.xpoint.tech/releases/

For anything else contact Xpoint Support Team.
